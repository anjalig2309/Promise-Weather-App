A simple weather app built using HTML, CSS, and JavaScript Promises — without using any real API.
This project simulates API behavior manually with delayed responses using Promise, .then() and .catch().

Features

1. Promise-based fake API simulation

2. Shows Loading State (⏳ Fetching...)
   
3. Displays temperature and condition for stored cities

4. Error handling for invalid cities

5. Fully offline — no internet/API required

6. Beginner-friendly project to understand Promise
